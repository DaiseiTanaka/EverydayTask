# Split Commit: よくある失敗パターン

## 1. コンパイルできない中間コミット
ファイル分割を複数コミットに分けた際、途中のコミットでビルドが通らない状態を作ってしまう。各コミットが独立してビルドできることを確認すること。

## 2. 関連変更の分離
pbxproj の変更とソースファイルの変更を別コミットにすると、片方だけではビルドできない。Xcode プロジェクト登録とファイル追加は同じコミットにまとめること。

## 3. 差分の分析不足
変更内容を理解せずに機械的にファイル単位で分割すると、論理的に関連する変更が別コミットに分かれてしまう。変更の意図を理解してから分割すること。
