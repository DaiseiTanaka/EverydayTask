# PM: 要件整理＆タスク分解

対象: `$ARGUMENTS`

## 手順

1. ユーザーの要望を分析し、具体的な要件に落とし込む
2. 既存コードを調査して影響範囲を特定する
3. タスクを実装可能な粒度に分解する
4. リスクと注意点を洗い出す

Agent ツールで `pm` エージェント (`subagent_type` ではなく `.claude/agents/pm.md` を参照) を起動し、以下を実行させる:

1. `$ARGUMENTS` の要望を分析
2. 関連する既存コードを読み込み（Model, Service, Presenter, Screen）
3. 影響範囲マップを作成
4. タスク一覧を優先度付きで出力
5. データ安全性リスクを評価

結果をユーザーに提示し、実装方針の承認を得る。
