# Implement: よくある失敗パターン

## 1. Codable プロパティのデフォルト値未設定
新規プロパティ追加時にデフォルト値がないと、既存データのデコードが失敗する。後方互換性のため必ずデフォルト値を設定すること。

## 2. 強制アンラップの混入
`as!` や `try!` は禁止。`guard let` / `if let` / `??` を使うこと。

## 3. 初期値の上書きによるデータ消失
編集画面でプロパティを新しい値で初期化する際、既存データを保持するか確認すること。

## 4. ハードコードの混入
定数は専用の enum/struct にまとめる。マジックナンバーや固定文字列を直接使わないこと。
