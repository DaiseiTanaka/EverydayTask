# QA レビュー

対象: `$ARGUMENTS`（未指定時は `git diff` の差分全体）

## 手順

Agent ツールで `qa` エージェント (`.claude/agents/qa.md`) を起動し、以下を実行させる:

### 1. 差分の把握
- `git diff --stat` で変更ファイル一覧を取得
- 変更ファイルをすべて読み込む
- 変更ファイルの依存先・参照元も読み込む

### 2. P0: データ安全性チェック（最重要）
- データ消失リスクがないか
- 保存・ロードフローに不具合がないか
- 後方互換性（Codable デフォルト値）
- 初期ユーザー / 大量データユーザー
- データ欠損時の復元可能性
- 機種変更対応
- dev/prd 環境切り替え
- スクリーンショットモード / 初期ユーザーモード

### 3. P1: 機能整合性チェック
- 全画面での仕様統一
- デグレ確認
- 副作用の考慮
- 例外パターン対応
- 通知ロジック
- 未修正機能への影響

### 4. P2: コード品質チェック
- 強制アンラップ、ハードコード
- 命名、アクセス修飾子
- デッドコード、未使用 import
- 共通化可能なロジック

### 5. P3: 設計チェック
- 層構造の遵守
- 依存方向の正しさ
- 責務の分離

### 6. テスト観点の出力
- 正常系 / 異常系 / エッジケース / データパターン

### 7. 判定
- P0/P1 問題がなければリリース可と判定
