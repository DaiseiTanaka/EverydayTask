# QA: よくある失敗パターン

## 1. Codable プロパティの後方互換性
新しいプロパティを追加した際、デフォルト値がないと既存データのデコードが失敗する。必ずデフォルト値を設定すること。

## 2. 初期ユーザーと長期ユーザーの両方でのテスト
空の状態とデータが蓄積された状態の両方で動作確認すること。特にパフォーマンスと空状態の UI を確認。

## 3. 強制アンラップの混入
`as!` や `try!` は禁止。`guard let` / `if let` / `??` を使うこと。

## 4. 画面間の仕様不統一
同じ操作が画面ごとに異なる挙動をしていないか確認すること。
